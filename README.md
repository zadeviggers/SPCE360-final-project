## Appendix 1: Spectral analysis code
The code to generate the spectral plots uses the EMIT L2A reflectance NC files from NASA  consists of two iPython notebooks.

The first notebook (geo_classify_nc_to_tif.ipynb) takes the NASA nc files and produces georeferenced tif files which may then be masked in QGIS using the process described in the Methods section, and also extracts the parameter values into a csv file for use when generating the charts.

The second notebook (compare-avg-spectra.ipynb) takes the masked before and after L2A reflectance images produced in QGIS, the CSV file generated by the previous script, a geojson file of polygon area of interest masks within the study site produced manually in QGIS, and a CSV file of expected spectral responses for each clay type retrieved from a spectral database, and produces the spectral plots seen above in the report.
